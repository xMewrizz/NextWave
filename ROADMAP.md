# План работ

## Текущая цель

Подготовить квалификационный MVP v1 к **29 сентября 2026 года**. Отбор проходят 10 команд, поэтому релиз должен одновременно доказать базовую точность, работу открытого поиска и одно запоминающееся конкурентное преимущество.

**Статус на 16 сентября:** основа репозитория, демонстрационные API, интерфейс и Docker подготовлены. Следующая задача — V1-03: преобразовать 100 строк организаторов в положительный обучающий класс и отделить балл силы сигнала от target. Затем команда собирает отрицательный корпус для V1-04.

## Конкурентное преимущество MVP

NextWave использует **Evidence Duel + anti-echo**:

- `signal case` показывает доказательства раннего появления;
- `skeptic case` показывает признаки зрелости, хайпа и шума;
- anti-echo объединяет перепечатки вокруг общего первоисточника;
- один исторический кейс проверяет, что метод работает только на данных, доступных до даты среза.

Граф траектории и межотраслевой transfer detector остаются в MVP v2.

## Критические последовательности

ML-контур:

`V1-03 → V1-04 → V1-05 → V1-06 → V1-09`

Открытый поиск:

`V1-07 → V1-08 → V1-09 → V1-10`

Конкурентный demo:

`V1-08 → V1-09 → V1-10 → V1-11`

V1-04 и V1-07 можно выполнять параллельно разными участниками. Общий feature contract фиксируется до соединения контуров.

## Что сокращается при отставании

1. декоративные элементы интерфейса;
2. модели после Logistic Regression;
3. коннекторы сверх двух стабильных классов;
4. дополнительные функции Evidence Duel вне одного сильного demo;
5. расширенная историческая аналитика.

Не сокращаются общий feature path, честная оценка, реальные источники, provenance, фильтр зрелости, объяснение и чистый запуск.
