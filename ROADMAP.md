# План работ

## Текущая цель

Подготовить квалификационный MVP v1 к промежуточной сдаче **29 сентября 2026 года**. Функции финальной версии добавляются только после выполнения обязательных условий отбора.

Идентификаторы **V1-xx** относятся к квалификационной версии, **V2-xx** — к версии финалиста..

## Параллельная работа

Критическая ML-последовательность:

**V1-01 → V1-02 → V1-03 → V1-04 → V1-05 → V1-06 → V1-08 → V1-09**

После принятия общих контрактов в V1-02 работа разделяется:

- ML-контур: V1-03, V1-04, V1-05, V1-06, V1-08, V1-09;
- программный контур: V1-07, V1-10, V1-11;
- интеграция и выпуск: V1-10, V1-11, V1-12.

Изменение общего контракта проверяется обоими владельцами.

## Сокращение scope при отставании

Работа сокращается в следующем порядке:

1. оформление интерфейса и необязательные графики;
2. дополнительные семейства моделей;
3. коннекторы сверх двух стабильных классов источников;
4. углублённая историческая аналитика;
5. необязательные функции фоновых jobs.

Общий feature path, интерпретируемая модель, метрики, свободный запрос, проверяемые источники, фильтр зрелости и воспроизводимый запуск не исключаются.
