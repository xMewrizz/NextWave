# Проверенный демонстрационный snapshot

Каталог `result/` содержит неизменяемый `analysis-result-v2` для запроса
«Инфраструктурные технологии для обучения и инференса ИИ». Backend проверяет
размер и SHA-256 каждого файла перед показом. Это позволяет поднять интерфейс из
чистого clone без API-ключей и внешней сети.

Каталог `model/` содержит зафиксированную Logistic Regression и диагностический
grouped-CV отчёт, использованные при построении snapshot. Метрика имеет статус
`development_only`: отрицательный корпус не достиг целевого баланса 50 mature / 50
marketing hype, поэтому её нельзя выдавать за результат на закрытом ground truth.

В каталоге нет исходного датасета, секретов, HTTP-cache, LLM-ответов или рабочих
checkpoint. Произвольный запрос выполняется отдельно в live-режиме и требует
серверных ключей OpenAI, OpenAlex и Exa согласно корневому `README.md`.
