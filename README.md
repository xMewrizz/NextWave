# NextWave

NextWave — сервис для поиска зарождающихся научно-технологических трендов по пользовательскому запросу. Система собирает материалы из открытых источников, формирует технологических кандидатов, оценивает их по интерпретируемым признакам, исключает зрелые технологии и возвращает ранжированную выдачу с проверяемыми основаниями.

Проект разрабатывается для задачи Газпромбанк.Тех на хакатоне 2026 года.

## Текущий статус

Подготовлены основа репозитория и общие контракты.

Ближайший релиз — квалификационная версия для промежуточной сдачи **29 сентября 2026 года**. Версия финалиста планируется после результатов отбора. Требования финальной версии переносятся в текущую работу только после выполнения всей обязательной приёмки квалификационного релиза.

## Основной подход

NextWave классифицирует технологического кандидата, а не отдельную статью. Два контура решения используют общий контракт признаков:

1. Офлайн-контур строит признаки кандидатов, обучает интерпретируемую модель на development-данных и передаёт предсказания на оценку по протоколу организаторов.
2. Онлайн-контур принимает свободный запрос, собирает актуальные источники, извлекает и объединяет кандидатов, формирует те же базовые признаки и применяет сохранённую модель.
3. Фильтр зрелости и качества оснований исключает зрелые технологии, стандарты, неподтверждённый хайп и нерелевантные результаты.
4. Отдельный алгоритм ранжирует допущенных кандидатов. Приоритет исследования не выдаётся за вероятность коммерческого успеха.

LLM-компоненты могут извлекать структурированные факты, нормализовать названия, переводить и составлять резюме по найденным материалам. Итоговая выдача не формируется только из знаний языковой модели.

## Результат промежуточной сдачи

Квалификационная версия должна включать:

- воспроизводимую обработку датасета и построение признаков;
- интерпретируемый метод классификации и отчёт с метриками;
- свободный запрос по технологическому направлению;
- сбор и обработку реальных открытых источников;
- извлечение, объединение и ранжирование кандидатов;
- скоринг, краткое объяснение и ссылки для каждого результата;
- название, URL, дату, тип, язык и уровень доверенности источника;
- явное исключение зрелых технологий, маркетингового хайпа и шума;
- базовый технический интерфейс и воспроизводимое развёртывание.

## Проверка основы проекта

Windows PowerShell:

```powershell
py -3.13 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
python -m unittest discover -s tests -v
python -m nextwave --version
```

Сейчас команды проверяют только установку пакета и общие контракты.

## Роли

- **ML Engineer:** анализ датасета, development-разметка, признаки, моделирование, оценка, объединение кандидатов, фильтр зрелости и ранжирование.
- **Software Engineer:** коннекторы источников, хранение, jobs, API, интерфейс, развёртывание и эксплуатационная надёжность.
- **Команда:** общие контракты, интеграция, выпуск и коммуникация с организаторами.

## Данные и секреты

Датасет организаторов, загруженные материалы, обученные артефакты, локальные базы и секреты по умолчанию не коммитятся. Перед релизом фиксируются их версия, расположение и допустимость публикации. Названия переменных окружения перечислены в `.env.example`, реальные значения остаются вне Git.
