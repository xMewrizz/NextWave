# Отчёт об оценке модели

## Задача

Модель ранжирует технологических кандидатов по сходству со слабым сигналом. Положительный класс состоит из 100 размеченных организаторами примеров. Отрицательный корпус содержит 57 проверенных зрелых технологий и 7 проверенных примеров маркетингового хайпа. Ещё 36 автоматически предложенных hype-примеров не используются как ground truth.

## Протокол оценки

- модель: Logistic Regression с L2-регуляризацией;
- признаки: структурные временные показатели и ограниченные текстовые n-grams;
- схема: deterministic stratified grouped 5-fold cross-validation;
- группа: identity технологии со всеми aliases;
- порог решения: фиксированный 0.5 без настройки на test fold;
- экспертные поля и proposed labels исключены из признаков;
- временные counts получены без искусственного ограничения числа страниц.

## Интерпретируемость

Для каждого прогноза сохраняются исходный model score, глобальные коэффициенты модели, локальные вклады признаков и ведущие факторы, повысившие или понизившие оценку. Интерфейс переводит технические признаки на пользовательский язык. Model score используется для ранжирования и не называется откалиброванной вероятностью.

## Ограничения оценки

Это внутренняя воспроизводимая оценка, а не результат на скрытом ground truth организаторов. Положительный класс предоставлен организаторами, отрицательный корпус собран командой и пока несбалансирован по подтипам: mature представлен лучше, чем marketing hype. Возможен стилевой сдвиг между источниками классов.

Поэтому отчёт подтверждает работоспособность выбранной модели и превышение целевого порога на доступном корпусе, но не заявляет официальную квалификационную точность.
